# VTA activity analysis

Code supporting the LISBET analysis of VTA putative dopaminergic-neuron (VTA-pDA) activity beyond velocity and inter-mouse distance in the Nature Neuroscience revision.

## Scope and provenance

This is a reorganized, path-portable release assembled from the actual VTA analysis files supplied for the revision. It contains no synthetic data and no raw or row-level VTA data.

The provenance of each code file is explicit:

- `scripts/01_prepare_vta_event_unit_table.py` contains the event-table and event-unit-table preparation section of `run_vta_lisbet_posthoc_conditionA_same_as_yours_fixed.py`. Relative to that source section, only input/output path handling and terminal status messages were changed.
- `scripts/02_run_vta_model_comparison.py` wraps the model-comparison and residual-analysis section of the same source script in a command-line interface. The formulas and statistical calculations are unchanged.
- `scripts/03_run_vta_robustness_analyses.py` is byte-for-byte identical to the supplied `run_vta_lisbet_residual_robustness_fast.py`.
- `notebooks/04_plot_vta_figure.ipynb` contains the exact final plotting code cell from the supplied `vta-plots.ipynb`; saved outputs and earlier exploratory cells were removed.
- `config/lisbet.mplstyle` is byte-for-byte identical to the supplied plotting style file.

The archived row-level output recorded its source trial paths under:

```text
restricted VTA Condition_A directory
```

This confirms that the retained Condition_A analysis table was generated from that source tree. Exact file hashes and the audit record are provided in `PROVENANCE.md` and `metadata/source_checksums.csv`.

`metadata/data_dictionary.csv` and `metadata/dataset_summary.csv` are release documentation derived from the supplied source code and archived outputs.

## Restricted inputs

Each Condition_A trial directory is expected to contain:

```text
features_metrics.csv
hmmbet_state_predictions.csv
```

Raw recordings, original trial identifiers, private network paths, and row-level event/event-unit tables are not included. Access must follow the manuscript Data Availability statement and approval of the data owners.

## Software environment

The exact execution environment was not available in the supplied analysis archive and is therefore not included here. The scripts should be run in a compatible LISBET Python environment containing the packages imported by the released code.

## 1. Prepare event and event-unit tables

Set the restricted dataset root and a private output directory:

```bash
export DATASET_ROOT=/path/to/LISBET/DATASET
export VTA_ROOT=/restricted/path/to/vta_condition_directories
export TARGET_CONDITION=Condition_A
export OUTDIR=/private/path/vta_posthoc_results

python scripts/01_prepare_vta_event_unit_table.py
```

This creates restricted derived tables:

```text
trial_status_summary.csv
figure6_all_trials_event_table.csv
figure6_all_trials_event_neuron_long_valid.csv
```

Do not commit these files to a public repository.

## 2. Run the OLS model comparison and residual analysis

```bash
python scripts/02_run_vta_model_comparison.py \
  --long-csv /private/path/vta_posthoc_results/figure6_all_trials_event_neuron_long_valid.csv \
  --outdir /private/path/vta_posthoc_results/model_comparison
```

The models are:

```text
neural_z ~ velocity_z + distance_z + C(unit_id)
neural_z ~ velocity_z + distance_z + C(prototype_id) + C(unit_id)
```

This script reproduces the archived OLS R², ΔR², AIC, BIC, and likelihood-ratio outputs. The nested-model F-test reported in the manuscript is generated by the robustness script below.

## 3. Run robustness analyses and the manuscript F-test

The manuscript run used 5,000 trial-level bootstrap samples and 5,000 within-trial permutations:

```bash
python scripts/03_run_vta_robustness_analyses.py \
  --long-csv /private/path/vta_posthoc_results/figure6_all_trials_event_neuron_long_valid.csv \
  --outdir /private/path/vta_posthoc_results/robust_residual_analysis_final \
  --style config/lisbet.mplstyle \
  --n-boot 5000 \
  --n-perm 5000 \
  --seed 42
```

This script performs the nested-model F-test, extended-control analysis, residual analysis, trial-cluster bootstrap, leave-one-trial-out analysis, and within-trial permutation test.

## 4. Plot the VTA figure

Open `notebooks/04_plot_vta_figure.ipynb` after generating the robustness outputs. The retained code cell is the final plotting cell from the supplied notebook.

## Verified reference totals

The archived Condition_A run contained:

- 101 trials
- 134 recorded units
- 62,547 prototype events before duration filtering
- 22,797 retained events after the 0.2–2.0 s duration filter
- 30,008 event-unit observations
- 7 retained prototypes

The verified primary model-comparison checkpoints are:

- baseline R²: 0.0042669707
- augmented R²: 0.0056272493
- ΔR²: 0.0013602786
- ΔAIC (baseline minus augmented): 29.0221885
- nested-model F(6, 30000): 6.839883
- nested-model p: 2.877355 × 10⁻⁷

The verified residual-analysis checkpoints are:

- residual ΔR²: 0.0010412763
- residual-model p: 2.258110 × 10⁻⁵
- within-trial permutation p with 5,000 permutations: 0.00019996001
